# Metronome Roadmap

Last updated: 2026-09-01. Work is ordered by user value and technical dependency.

## Product priority

1. **P0 — Precision foundation:** timing accuracy, audio reliability, accessibility, localization, and maintainable practice architecture.
2. **P1 — Structured practice:** named presets and reusable Practice Sets that help musicians prepare, play, and finish focused sessions.
3. **P2 — Faster control:** favourites, recents, hardware shortcuts, widgets, and other ways to operate the instrument with less interruption.
4. **P3 — Private insight:** useful local practice history and progress without accounts, leaderboards, badges, or pressure mechanics.

P0 is a continuous release gate. P1 is the current product investment. P2 builds on P1's durable preset model, and P3 builds on real sessions generated by P1.

## Shipped

### Practice tools redesign

- Practice timer redesign: bottom-sheet configuration, mode-aware timer chip, extend and restart, and custom durations
- Tempo sheet: presets, saved tempos, subdivisions, tempo trainer, and gap trainer in a single-expanded accordion
- Ascending and descending tempo trainer with persisted configuration
- Gap trainer with play and muted bar cycles
- Eighth-note, triplet, and sixteenth-note subdivisions
- Per-beat accent and mute controls
- Saved tempo bookmarks for BPM, time signature, and subdivision
- Daily, streak, and total practice statistics stored locally
- Count-in, pendulum display, keep-screen-awake option, UI haptics, and multiple colour schemes
- Android background playback and iOS background playback
- iOS Live Activity and Dynamic Island controls
- Shared Compose component and motion system
- Native in-app review prompt after a qualifying practice pause
- Accessibility semantics, 48dp targets, responsive typography, and adaptive 480dp content width

## Now

### P0 — Release quality and precision

- Complete on-device audio checks across high BPM values, subdivisions, click sounds, interruptions, Bluetooth routes, and background playback
- Replace per-beat delay scheduling with cumulative monotonic target timestamps before adding polyrhythms
- Resolve iOS audio graph serialization and Android load-then-swap/audio-focus behavior
- Complete VoiceOver and TalkBack traversal, text scaling, reduced-motion, and compact-screen checks
- Move hardcoded English UI text into Compose resources, then add ES, DE, PT, and JA
- Split the growing `MetronomeViewModel` into focused timer, trainer, session, and preset state holders as each area is changed

### P1A — Practice Presets Foundation

- Replace anonymous saved tempos with stable, editable, named Practice Presets
- Capture BPM, time signature, subdivision, beat accents and mutes, and count-in state
- Migrate every existing saved tempo without data loss and generate a useful default name
- Create a focused preset library with search-free scanning, favourites, recents, reordering, rename, duplicate, apply, and delete
- Keep instant preset recall in the tempo sheet while moving management into a dedicated full-screen flow
- Add clear empty, maximum-capacity, name-validation, destructive-confirmation, and migration states
- Preserve the main metronome as the dominant screen and show only concise preset context there
- Add deterministic model, migration, repository, ViewModel, and Compose behavior tests

The design is recorded for review in `docs/superpowers/specs/2026-09-01-practice-presets-foundation-design.md`.

## Next

### P1B — Practice Sets

- Combine presets into ordered Practice Sets for warmups, exercises, repertoire, rehearsals, and performance orders
- Give each step an optional duration or bar target
- Provide previous, pause, next, finish, and safe resume controls
- Show one restrained active-practice strip on the main instrument
- Keep manual progression as the default; add optional hands-free advancement only after the core flow proves reliable

### P2A — Faster recall

- Add “Practice again” from the most recent completed set
- Surface recent and favourite presets without opening the full library
- Add deliberate long-press shortcuts where they do not conflict with accessibility
- Extend the existing Live Activity snapshot seam to an Android home-screen widget

## Later

### P2B — Hands-free and external control

- Hardware keyboard and Bluetooth pedal shortcuts
- Apple Watch and Wear OS play, pause, tempo, and step controls
- Lock-screen and widget shortcuts appropriate to each platform
- Ableton Link and MIDI clock sync

### P3 — Private practice insight

- Local session history generated from actual playback
- Time practised by preset and Practice Set
- Weekly consistency and tempo progression
- Optional short session note
- Calendar history and simple, readable trends
- Export and delete controls
- Optional local reminders that never depend on streak pressure

### Additional serious practice tools

- Polyrhythms after the unified scheduler is complete
- More click sounds and per-sound accent pitch
- Set sharing only if it can preserve local-first, account-free use

## Explicit non-goals

- No account requirement for core practice
- No subscription pressure, advertisements, or artificial feature friction
- No leaderboards, levels, badges, celebratory clutter, or “10,000-hour” mechanics
- No dashboard replacing the metronome as the primary surface
- No cloud synchronization until there is a specific user need and privacy contract
- No tuner or recorder expansion before the core timing and structured-practice experience is excellent

## Known technical debt

- Sessions spanning midnight currently credit all time to the pause day
- Streak flows do not re-evaluate at midnight while the app stays open
- Onboarding coach marks reference beat circles and should adapt to pendulum mode
- The repository privacy policy and Google Play data declaration must be reconciled
- `docs/index.html` still references an obsolete App Store ID
