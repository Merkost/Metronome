## Description

Find your tempo. Make room for practice.

Metronome brings a clear, focused pulse and a useful practice toolkit to your Mac. Set a tempo, choose a click and build a rhythm that works for the way you play.

Shape the beat

Adjust BPM, time signature, subdivisions and individual beats. Give important beats an accent, mute a beat, or choose a different click sound for your session.

Practice with a plan

Use the timer, tempo trainer and gap trainer to give each session a purpose. Save useful setups, organize practice routines and track your daily practice time, total time and streaks on your Mac.

Make yourself comfortable

Choose a light or dark appearance and a color scheme that suits your space. Keep the instrument beside your music and use the Mac's keyboard and window controls as you practice.

Your practice stays yours

Core metronome and practice features work offline. No account, advertisements or subscription is required. Settings and practice data are stored on your Mac.

Requires an Apple silicon Mac with macOS 13 or later.

## Review notes

Metronome is a free music practice utility. No sign-in or purchase is required. The core metronome and practice tools work offline. To test audio, open the instrument and press Play. To test structured practice, open Practice, then the timer or a trainer. Import and export use the Mac's native file panels and require the user to choose a file or destination.

The app includes its own arm64 Java runtime, native rendering libraries and audio resources. It does not require a separate Java installation, download executable code, install shared components, run an updater or request microphone access. The JVM JIT entitlement supports the bundled runtime. User-selected file access supports import and export. The application is sandboxed.

The existing account's review contact information is retained, sign-in is not required, and automatic release after approval remains selected. Build delivery, processing, selection and review submission are complete. Apple approval and public Mac availability remain pending. First-release notes above are prepared locally; Apple does not expose a What's New field for this first Mac version.
